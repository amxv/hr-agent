## Phase 1: Database Schema and Type Definitions

### Overview

Establish the complete database foundation for the HR Tools Admin Integration feature by defining all 12 tables (employee, leaveBalance, blackoutDate, leavePolicy, benefitsPlan, benefitsEnrollment, dependent, enrollmentPeriod, hrCase, caseUpdate, absence, leaveRequest), relationships, enums, indexes, and shared types. This phase creates the "source of truth" database structure that will support the admin UI and agent tool integrations in subsequent phases.
