# HR Tools Admin Integration - Phase 4: Admin UI - Benefits, Cases, and Availability

## Phase Overview

Complete the admin interface with benefits management, HR cases, and team availability sections. This phase follows the same UI patterns established in Phase 3.

**Dependencies**: This phase depends on Phase 3 being complete (dashboard, employees, leave balances UI implemented).

**References**:
- See `gg/features/003-hr-tools-admin-integration/summary.md` for the complete feature overview and implementation approach.
- See Phase 1 plan for Database Schema and Shared Type Definitions.
- See Phase 2 plan for all available tRPC procedures.
- See Phase 3 plan for established UI patterns (dialog-based CRUD, list tables, form patterns).

**File**: `components/admin/create-benefits-plan-dialog.tsx`

- **Retirement**: Employer Match Percent, Vesting Schedule
- **HSA/FSA**: Contribution limits, employer contribution

Form behavior:
- Dynamic field display based on category selection
- JSON editor for complex coverage details (or structured form fields)
- Zod validation per category
- Success toast on creation
- Duplicate plan option (copy existing plan and modify)

Denial dialog:

- Confirmation: "Are you sure you want to deny this request?"
