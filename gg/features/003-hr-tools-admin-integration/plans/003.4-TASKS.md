## Notes

- All components should follow existing code patterns from Phase 3 (dialog-based CRUD, React Hook Form + Zod, tRPC queries)
- Use consistent color coding and badge patterns from Phase 3
- Implement loading skeletons for all data-fetching tables
- All confirmation dialogs should have clear destructive action messaging
- All tRPC queries and mutations should be error-handled with appropriate toast notifications
- Form validation should use Zod schemas that match backend validation
- Consider performance: tables should handle up to 100+ records efficiently
- Accessibility must follow CLAUDE.md rules (no aria-hidden on focusable elements, proper labels, keyboard navigation)
